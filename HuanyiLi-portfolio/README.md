# Huanyi Li — Portfolio

An interactive portfolio for interaction and experience design, built with React, TypeScript and Vite.

## Development

Install Node.js, then run:

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The production files are generated in `dist/`. Configure a static host with build command `npm run build` and output directory `dist`.

## Editing

- `src/App.tsx`: profile, skills, experience and contact details
- `src/editorial.css`: layout and visual styles
- `src/ui/BookShelf.tsx`: bookshelf order and interactions
- `src/content/works/`: individual project descriptions
- `public/assets/`: images, original résumé and final presentation

Includes a blinking pixel avatar, mouse-driven bookshelf, touch navigation, and project book reader.
